# Лабораторная работа №1: Клиент-серверное взаимодействие

## Описание
Простое веб-приложение на FastAPI, которое возвращает количество дней до Нового года.  
Приложение доступно по маршруту `GET /info`.

## Технологии
1. Python 3.9+
2. FastAPI
3. Uvicorn
4. Docker

### Требования
[Docker](https://docs.docker.com/get-docker/) и [Docker Compose](https://docs.docker.com/compose/install/) (входят в Docker Desktop)

### Инструкция
1. Клонируйте репозиторий или скопируйте файлы в папку `lab1`.
2. Откройте терминал в этой папке.
3. Выполните команду:
   ```bash
   docker-compose up --build
4. После успешной сборки и запуска приложение будет доступно по адресу: 
http://localhost:4200/info
